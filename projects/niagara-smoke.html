제작 과정

1. 연무의 소스 구성

모래 효과를 만든 뒤에는 같은 구성을 이용해 드라이아이스처럼 바닥에 퍼지는 연무를 만들고 싶어 소스를 정적 메시로 바꾸고 입자에 중력을 추가했다.

소스 입자는 직접 보이지 않도록 Sprite Renderer를 끄고 기존 Grid3D Gas를 유지한 상태에서 Wind를 아래쪽으로 설정했고 바닥 주변에서 연무가 퍼지도록 Mesh Collision도 사용했다.

2. 연무 흐름 조절

연무가 오래 남는 정도는 Density Dissipation을 1.5로 조절하며 맞췄고 소스 입자의 움직임과 가스의 흐름을 따로 바꿔가며 결과를 확인했다.

3. 스파크 추가

연무와 함께 스파크를 표현하기 위해 Cylinder 범위에 입자를 생성하고 초기 속도를 준 뒤 중력과 바닥 충돌을 연결했다.

입자가 빠르게 커졌다가 점차 작아지며 사라지도록 크기 곡선을 조절했고 Scale Color로 색상 배율을 바꾼 뒤 주변 표면에도 빛이 닿도록 Light Renderer를 추가했다.

4. 전기 효과 추가

연무와 스파크를 배치한 장면에 세 기둥을 잇는 전기 효과를 추가하고 싶어 CPU 이미터 세 개를 사용해 삼각형으로 연결했다.

Beam Emitter Setup에서 시작점과 끝점을 지정하고 Spawn Burst Instantaneous로 입자 50개를 한 번에 생성한 뒤 Spawn Beam으로 두 점 사이에 배치하고 Ribbon Renderer로 이어줬다.

시작점과 끝점에는 높이가 조금 다른 위치 두 개를 배열로 넣고 Select Position from Array에서 무작위로 선택하게 해 새로 생기는 빔의 연결 위치에도 차이를 줬다.

5. 반복 주기와 수명 조절

빔이 빠르게 사라졌다가 다시 나타나도록 Life Cycle Mode를 Self로 설정하고 0.1초마다 Burst가 반복되게 만들었는데 이전 입자가 오래 남으면서 전기줄이 너무 두껍게 보였다.

Initialize Particle의 Lifetime을 0.5초로 줄여 입자가 남는 시간을 조절했고 반복해서 생성되는 빔이 겹치면서도 빠르게 모양이 바뀌도록 맞췄다.

6. 두께와 흔들림 조절

일자로 이어진 빔에 변화를 주기 위해 Beam Width에 커브를 연결하고 RibbonLinkOrder를 기준으로 가운데가 조금 더 굵고 양 끝은 얇아지도록 조절했다.

Jitter Position에도 연결 순서를 기준으로 커브를 넣어 양 끝의 흔들림은 줄이고 가운데가 강하게 흔들리도록 만들었고 Random Vector를 사용해 불규칙한 움직임을 더했다.

7. 양쪽으로 약해지는 머티리얼

기본 리본 머티리얼은 한쪽으로만 흐려지는 형태여서 TexCoord의 U 값과 OneMinus로 반전한 값을 곱해 양쪽 가장자리가 흐려지도록 수정했다.

Particle Color의 RGB는 Emissive에 연결하고 Alpha는 두 마스크에 각각 곱한 뒤 Opacity로 연결해 중앙이 남고 UV 양 끝으로 갈수록 사라지는 형태를 만들었다.
