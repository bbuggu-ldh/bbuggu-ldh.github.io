Material
system

모듈식 마스터 머티리얼

표면 효과를 기능별로 나누고 필요한 값만 아티스트가 고를 수 있도록 머티리얼 시스템을 구성했다.

제작 과정 읽기 ↓

대전 에셋사업 / 머티리얼
2025 — 2026

아래로 스크롤 ↓

대전 에셋사업의 경복궁과 국회의사당 환경을 제작하면서 반복해서 쓸 머티리얼 시스템도 만들었다. 표면 효과를 Material Function으로 나눠 플러그인으로 묶고 필요한 기능을 조합해 각 환경에 적용했다.

효과를 조합하는 구조#

World-Aligned 투영을 바탕으로 Vertex Color가 제어하는 레이어를 얹고 Dirt·Sand·Moss·Leakage 효과를 조합했으며 Snow·Leaves 축적은 Z 마스크로 처리했다.

각 효과를 Material Function으로 분리한 뒤 Function Library를 플러그인으로 패키징해 다음 프로젝트에서도 반복해서 쓸 수 있는 단위로 만들었다.

아티스트가 선택할 값#

표면마다 필요한 투영 방식이 달라 일반 UV와 World-Aligned를 선택하도록 했고, World-Aligned 안에서도 XYZ와 XY 축을 고를 수 있게 나눴다.

제어 항목노출한 선택
텍스처 투영일반 UV / World-Aligned
투영 축XYZ / XY
레이어 속성상수값 / 텍스처
전역 환경MPC를 통한 계절·날씨·시간·눈 높이·바람 강도

컬러·메탈릭·UV 타일링·러프니스는 레이어마다 조절하도록 하고 내부 블렌딩 연산과 노이즈 파라미터는 숨겨 결과를 판단하는 데 필요한 값을 남겼다.

기능을 끄는 것과 순열을 줄이는 것#

주요 기능에는 Static Switch Parameter를 사용해 꺼둔 기능이 컴파일 단계에서 빠지도록 했다. 다만 실제로 쓰는 스위치 조합마다 별도의 셰이더 맵이 만들어진다.

런타임 비용과 컴파일·쿡 시간, 셰이더 메모리는 서로 다른 문제라 기능을 켜는 조합과 사용하지 않는 Used with 설정을 함께 점검해야 했다. 런타임에 바뀌는 계절과 날씨는 MPC로 제어했다.

통합의 경계#

기능을 통합하면 관리와 재사용은 편해지지만 단순한 표면에 불필요한 비용이 남을 수 있었다. 바닥처럼 위를 향하는 표면에는 일반 UV를 쓰고 UV를 펴기 어려운 벽이나 바위에는 World-Aligned를 쓰도록 용도를 나눴다.

기존 케이스에서는 Platform Stats로 기능별 instruction과 텍스처 읽기 횟수를 비교했다. 다만 instruction 수는 실제 GPU 시간과 같지 않아 이 수치를 프레임 성능 개선으로 환산하지 않는다.

적용 규모와 셰이더 비용#

제출한 포트폴리오의 경복궁 환경 기록에서 새로 설계한 마스터 10종은 인스턴스 1,049개와 고유 메시 799종에 사용됐고 그중 한 마스터가 인스턴스 313개, 고유 메시 459종, 씬 배치 12,473개를 담당했다. 전체 씬에 존재하는 모든 마스터의 합계는 아니다.

DirectX SM6의 Platform Stats에서 기능 조건을 비교했다. 베이스는 Vertex Blending A 레이어만 켠 상태다.
