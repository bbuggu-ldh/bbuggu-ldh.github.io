한 페이지 요약

튜토리얼의 Root 소켓 기반 원형 눌림을 출발점으로 삼았습니다. 직접 확장한 범위는 발별 접촉 판정, 발바닥 이미지의 위치·경계·회전 처리, 깊이에 따른 눌림과 발별 상태 관리입니다. 발별 접촉 위치를 RT에 기록하고 노말·WPO로 눈의 반응을 만들었습니다. 원형 브러시를 발바닥 이미지로 확장하고, Timeline 대신 발이 눈에 들어간 깊이로 눌림을 조절했습니다. 이후 중복된 양발 검사를 UpdateFoot으로 통합하고 ST_FootState로 발별 상태를 나누는 리팩토링을 완료했습니다. 전체 기술 브레이크다운 읽기 →

원본 기술·수식 기록

발자국 글에는 구현 과정과 결과를 담았습니다. 좌표 변환·UV 회전·범위 마스크의 상세 계산은 별도 기술 노트로 분리했습니다. 별도의 학습 대화와 작업 문서 전체는 이 사이트에 게시하지 않았습니다.

트러블슈팅 전체 기록

별도 트러블슈팅 문서는 보관 중입니다. 공개한 기술 브레이크다운 2절에서 위치 오차, 가장자리 늘어짐, 방향 정렬의 문제와 수정 과정을 읽을 수 있습니다.

검산과 확인 범위

본문의 수식은 설명용 계산과 캡처에 남은 설정값을 구분합니다. 리팩토링 후 양발 생성은 실행 화면에서 확인했습니다. 최종 Blueprint 코드에서 FootState의 참조 전달 설정을 확인했습니다. Draw 호출만으로 실제 RT 기록 성공을 단정하지 않습니다. 리팩토링 후 실행 영상과 CPU·GPU 측정값은 없습니다. Render Target은 4096 × 4096, RTF_RGBA16f로 설정하고 Play 시작 시 초기화했습니다. Blend Mode와 합성 방식의 상세 설정은 별도 기록하지 않았습니다. 자세한 확인 범위는 기술 브레이크다운 6절과 글 끝의 확인 결과에 정리했습니다.

캡처 출처

발자국 이미지와 영상은 작업 중 보관한 원본 캡처입니다. 본문 이미지는 원문이 참조하는 파일입니다. 발자국 대표 이미지는 환경 적용 영상의 6초 프레임에서 에디터 테두리를 잘라 사용했습니다. 본문 캡처는 확대하면 원본을 확인할 수 있습니다.

상단 영상과 5.3절 영상은 같은 경사 지형 실행 기록입니다. 발별 상태 분리 전 기록이며, 리팩토링 완료를 보여주는 영상이 아닙니다. 6절의 노드 캡처 네 장은 연결을 구성하던 단계의 기록입니다. 최종 참조 전달 설정은 Blueprint 코드에서 확인했습니다. 긴 GIF는 초기 화면에서 내려받지 않습니다.

프로젝트 대표 이미지와 제작 자료

갤러리의 D.P. 시즌 2 대표 이미지는 Netflix 공식 발표의 시즌 2 포스터입니다. MBC 선거방송 대표 이미지는 iMBC 공식 기사에 실린 MBC 제공 「선택 2024」 표지입니다.

MBC·D.P. 시즌 2 본문의 제작 이미지와 MBC 스튜디오 셋업·작업 시간 기록 영상은 사이트 작성자가 제공한 작업 자료입니다. 본문에 삽입한 YouTube 영상은 각 영상 아래에 출처 링크를 표시한 공개 영상입니다.

작업 로그와 구현 순서

VHM 학습 기록에서 RT를 NormalFromHeightmap에 연결한 경로와, RT의 R값에 방향·Falloff·Depth를 적용해 WPO로 보내는 경로를 확인했습니다. 관련 그래프와 설명은 기술 브레이크다운의 노말·WPO 상세 자료에 수록했습니다. 이후 Timeline, 깊이 계산, 경사 지형 적용을 거쳐 2026년 10월 11일 UpdateFoot 공통화와 발별 상태 분리를 완료한 기록을 반영했습니다. ST_FootState에는 SocketName·IsActive·IsInspect를 묶고, LeftFootState와 RightFootState를 참조로 전달해 각각 갱신합니다. 각 단계는 왜 바꿨는지, 어떻게 구현했는지, 무엇을 확인했는지 순서로 이어집니다.

제출 자료에서 보강한 내용

자기소개서·경력기술서, 커버레터, 포트폴리오 PDF를 검토해 소개와 케이스 기록을 보강했습니다. 포트폴리오 5–9쪽은 머티리얼, 10–15쪽은 씬 최적화, 16–19쪽은 프로파일링 도구, 20–21쪽과 26쪽은 파이프라인 자동화의 근거입니다. 수치는 제출 자료의 기록이며 이번 사이트 작업에서 재측정하지 않았습니다. PDF 원문과 연락처, 지원 회사별 문구는 게시하지 않았습니다. 클러스터 설정 이미지는 포트폴리오 20쪽입니다.
